# flight-price-monitor

Flight Price Monitor（全球多航段机票搜索器）· 三步式中文 V1。

## 下载并使用

打开仓库中的 **`flight-price-monitor-v1.html`**，使用 Download raw file 下载完整文件，保存到 Windows 桌面并用 Microsoft Edge 打开。不需要安装 Node.js 或填写 API Key。不要复制部分源代码保存。

1. **输入旅行条件**：选择 A 个人专用或 B 通用旅行、机场与停留范围、出行月份、总天数及舱位。
2. **历史月份参考**：如实显示尚无可验证的历史整票数据，不生成虚假价格曲线；可以继续下一步。
3. **指定月份搜索**：选择快速候选或整月覆盖，查看计算量后点击“开始搜索（模拟）”，比较全程含税模拟总价。

A 默认墨尔本出发并返回、广州先停留，广州后首个旅游停留城市默认只允许 BKK/SIN/KUL 或用户加入的机场。短时转机不等于旅游停留。B 不受这些限制，允许自由起终点、单程/往返/异地结束、必经/避开机场和停留顺序比较。

旅行天数使用大号独立 ＋／－ 按钮，每次调整 1 天，也能直接输入。提高最短值超过最长值时自动抬高最长值；降低最长值低于最短值时自动降低最短值。两端相等代表固定天数。

两种模式分别保存设置和方案，支持导出/导入 JSON。14 天只是默认参考值，支持 7、10、21、30 天及更长，或 14～15 / 10～20 等范围。城市停留最短和最长值相同时是固定夜数，不会被自动延长。

## 数据与范围

**所有报价、航班时刻、航空公司组合、行李及汇率均为模拟，不代表实际可购买产品。** 多城市/往返整票采用独立模拟整票报价，不能把单程价相加后冒充联程价。缺价时不补造整票。

历史页没有真实数据，所有价格为缺失（不是 0）；模拟结果不会用于历史分析。无实时查价、后台监控、自动通知、预订或收费。

快速搜索选择当月 7 个候选出发日，明确不代表全月最低价；整月模式覆盖该月所有出发日。抵达日期可以跨月。总旅行长度按出发地时区的抵达日期减出发日期计算，最少为 1 天；逐段起降显示当地时间。

V1 最多 5 处旅游停留，一次最多 6,000 个时刻候选。超量时要求分批，而不是限制旅行总长度。结果保留总价最低 2,000 个，天数/日期汇总基于所有计算结果；如需商务舱完整比较，请在搜索前指定商务舱。

本地保存受浏览器设置影响，建议导出 JSON 备份。文件包含所有 CSS、JavaScript 与 Blob Worker 源码，无外部资源或服务器依赖。

## 验证与限制

已通过 15 项计算测试及受控浏览器检查：A/B 隔离、月内出发/跨月抵达、范围及固定停留、单程/异地结束、拆票覆盖、独立整票、缺价、模拟费用、真实历史缺失、预算拦截、取消、保存/导入导出、断网计算、安全与响应式布局。

当前执行环境的浏览器策略禁止 `file://` 导航，因此尚未在真实 Windows Edge 上验证桌面双击和本机存储行为；需下载后本机试用。真实航线、航班衔接、签证与行李保障不能由模拟结果确认。

## 开发者

运行和分享 HTML 不需要 Node.js。仅修改源码、重新生成文件和运行测试时使用 Node.js 20+，无第三方构建依赖。

```sh
npm test
npm run build
```

`src/core.mjs`：旅行规则、时区、月份候选、整票及组合计算。

`src/app.mjs`：三步流程、模式隔离、Worker、保存与备份。

`src/template.html` / `src/style.css`：中文界面。

`PROJECT_REQUIREMENTS.md`：整合后的项目需求。

构建同时更新 `flight-price-monitor-v1.html` 和旧文件名 `flight-price-monitor-v1-a.html`；两者内容一致，建议使用前者。旧 A 模式原型可从 Git 历史恢复。
