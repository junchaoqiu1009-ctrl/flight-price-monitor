# Flight Price Monitor · 全球多航段机票监控器

当前交付为 **V1 A 模式**，仅模拟报价和行程计算。独立项目，不修改金融看板或中文听力播放器。

## 普通使用者

下载 `flight-price-monitor-v1-a.html`，保存到 Windows 桌面，用 Edge 打开。无需安装 Node.js、注册报价服务或填写 API Key。所有 CSS、JavaScript、机场数据和本地计算线程代码均内嵌，没有外部资源依赖。仅在当前页面打开时计算，不后台监控、不预订机票、不产生费用。

- 默认墨尔本 MEL 出发、广州 CAN 停留、最终返回 MEL。
- 默认广州 5 夜；广州之后首站从 BKK/SIN/KUL 中自动比较，也可以指定。允许名单可编辑；短时转机不能代替旅游停留。
- 默认旅行长度 14 天，仅为初始值。可以设置 7、10、21、30、60 天等固定值，也可比较 10～20 天等范围，无 12～18 天硬限制。
- 停留夜数逐城市独立设置。总天数按墨尔本出发和返程抵达日期之差计算，旅游停留按当地日期计算；最后一站吸收余下可用时间。
- 比较独立的模拟单程、多城市、转机联程和非相邻开口往返整票。按完整旅行总价排序，提供同条件整张多城市票的价差（缺价则不计算）。
- 支持经济/商务/长途商务短途经济，1 位或多位成人，模拟行李补足，以及 AUD/CNY 模拟换算。
- 可保存方案、恢复设置、导出和导入 JSON。使用专属 localStorage key；不会读取其他项目的数据。存储不可用时用 JSON 文件备份。

## 重要边界

所有航班、承运人组合、日期时刻、价格、整票产品、行李和汇率均为 **模拟**，不保证航空公司实际有此航线或可购买此组合。多城市整票有独立模拟报价，不能称为实际可购买报价。缺失报价不以单程价补齐。

V1 为每种路线提供一套示范时刻表，只有返程可选择模拟直飞或香港转机 3 小时，不穷举真实航班时刻。取消红眼许可可能导致全部示范返程被排除；会如实报告无结果。不会确认真实 MCT 或签证要求。

界面最多 5 个停留城市；一次最多 5,000 个日期/旅行长度/路线组合，超出请分批。计算量限制不等于旅行总天数限制。结果保留总价最低的 2,000 个，旅行天数汇总基于所有计算结果；需要专看商务舱时请在搜索条件中选择商务舱。

没有真实查价、后台定时任务、真实历史价格或目标价通知。B 模式尚未实现，需求保留在 `PROJECT_REQUIREMENTS.md`。

## 开发者

运行和分享已生成的 HTML 不需要 Node.js。仅修改源码、重新打包和自动测试时需要 Node.js 20+；项目没有第三方运行或构建依赖。

```sh
npm test
npm run build
```

`src/core.mjs`：路线校验、时区日期、独立模拟整票目录和精确覆盖组合。

`src/app.mjs`：页面交互、Worker、本地保存、导入导出。

`src/template.html` / `src/style.css`：中文界面。

`scripts/build.mjs`：将上述文件打包为单个 HTML。
